# Isla Vista Parking Occupancy Prediction

This project analyzes parking availability patterns in Isla Vista (my college town) using spatial and temporal data.

I developed a predictive model to estimate parking availability by time and location, with the goal of helping users more efficiently find parking and reduce time spent searching.

## Live App

The project began as a predictive model trained on a year of IVCSD parking data. I then built it into a web tool so people could actually use the results to help them find parking!

**[ivpark.org](https://ivpark.org)**

It is featured on the [Isla Vista Community Services District website](https://islavistacsd.ca.gov/do-you-need-a-car-in-isla-vista) under transportation resources.

## Key Features

- Spatial and temporal analysis of parking demand
- Predictive modeling of occupancy patterns
- Visualization of trends by time and location
